# TWRP Device Tree for Samsung Galaxy A14 5G

The Galaxy A14 5G (codenamed _"a14x"_) is an low-range smartphone from Samsung.

It was announced and released in January 2023.

## Device specifications

| Feature                      | Specification                                                                  |
| ---------------------------: | :----------------------------------------------------------------------------- |
| Chipset                      | Exynos 1330                                                                    |
| CPU                          | Octa-core (2x2.4 GHz Cortex-A78 & 6x2.0 GHz Cortex-A55)                        |
| GPU                          | Mali-G68 MP2                                                                   |
| Memory                       | 4GB / 6GB / 8GB RAM (LPDDR4X)                                                  |
| Shipped OS                   | Android 13 (One UI 5.1)                                                        |
| Storage                      | 64GB / 128GB (UFS 2.2)                                                         |
| SIM                          | Single SIM (Nano-SIM) or Hybrid Dual SIM (Nano-SIM, dual stand-by)             |
| MicroSD                      | Up to 1TB                                                                      |
| Battery                      | 5000mAh Li-Po (non-removable), 25W fast charge                                 |
| Dimensions                   | 167.7 x 78 x 9.1 mm (6.60 x 3.07 x 0.36 in)                                    |
| Display                      | 6.6", 1080 x 2408 pixels, 20:9 ratio, LCD, 90Hz (~400 ppi density)             |
| Rear Camera 1       		   | 50 MP, f/1.8, (wide), 1/2.76", 0.64µm, PDAF                                    |
| Rear Camera 2                | 2 MP (macro)                                                                   |
| Rear Camera 3                | Auxiliary lens                                                                 |
| Front Camera                 | 32 MP, f/2.2, 26mm (wide), 1/2.8", 0.8µm                                       |
| Fingerprint                  | Fingerprint (side-mounted)                                                     |
| Sensors                      | Accelerometer, Gyro, Proximity (virtual), Compass                              |
| Extras                       | Dual speakers, NFC, MST, FM Radio                                              |
